# Security / Безопасность

Do not post account credentials, OAuth tokens, Discord user tokens or complete private logs in issues. This application does not need them.

Settings, the current status and bounded technical logs are stored under `%LOCALAPPDATA%/YandexMusicPresence/`. Review diagnostic text for personal paths before sharing it.

Report reproducible non-sensitive defects through [Issues](https://github.com/Xijk666/YandexMusicPresence/issues). If GitHub private vulnerability reporting is available for this repository, use it for sensitive reports.

---

Не публикуйте пароли, OAuth-токены, пользовательские токены Discord и приватные журналы. Приложение не требует этих данных. Перед отправкой диагностики проверьте личные пути. Обычные ошибки можно сообщить через Issues; для чувствительных сведений используйте приватное сообщение об уязвимости, если эта функция доступна в репозитории.
