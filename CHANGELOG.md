# Changelog / История изменений

## 1.1.0

- Redesigned compact player with a larger cover, consistent transport icons and a dark Windows title bar.
- Settings are on a separate scrollable page; connection internals stay in Diagnostics.
- Rounded controls, visible keyboard focus, bounded long titles and the headphone application icon.
- Isolated `--preview` mode for interface review without Discord or catalog requests.
- Новый компактный плеер, отдельные настройки, тёмный заголовок окна и значок с наушниками.

## 1.0.0

First public release / Первый публичный релиз.

- Yandex Music Windows media sessions → Discord Listening activity.
- Playing, pause, seek, elapsed/total timing and native Discord progress while playing.
- Album artwork, public track links and strict catalog matching with album-cover fallback.
- Alternate catalog endpoint and retries after missing artwork or network errors.
- Delayed SMTC thumbnails update without switching tracks.
- Russian desktop UI, system tray, automatic background mode and optional Windows startup.
- English/Russian documentation, 36 regression tests and a Windows build workflow.
